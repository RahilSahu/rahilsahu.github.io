05 hands-on

Playground — try it yourself.

Four small challenges rendered entirely in your browser. No servers, no tracking, no execution of your input — each check is client-side and read-only. Solve them for practice, or peek at the hint if you get stuck.

#01 HIGH

Bypass the sanitiser

A junior dev wrote this "XSS filter". It strips <script>, onerror=, onload=, and javascript:. Submit a payload that would still execute JavaScript. 

function sanitise(input) {
  return input
    .replace(/<script>/gi, '')
    .replace(/onerror=/gi, '')
    .replace(/onload=/gi,  '')
    .replace(/javascript:/gi, '');
}

#02 EASY

Find the flag

A flag in the format FLAG{...} is hidden somewhere in this challenge card. Not in visible text. Inspect the DOM (browser DevTools → Elements) and submit it.

There is nothing to see here — keep looking with the right tool.

The reference standard for LLM app security. Prompt injection, insecure output handling, model DoS, training-data poisoning — the map for testing GenAI systems.

Structured intro to prompt injection, jailbreaks, and prompt leaking. Read it before you test any LLM feature.

Live prompt-injection CTF. Coax secrets out of an LLM through progressively harder defenses. Best hands-on intro I know.

AI-augmented offensive framework I use in engagements. Orchestrates recon, scanning and exploitation across LLM-driven workflows.
